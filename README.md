## Introduction

This document contains code workflows, explaining how to perform the bioinformatics analysis described in ***Lymphoid aggregates distinguish clinically-relevant subgroups of peritoneal endometriosis***

An analysis of single cell transcriptomics and spatial proteomics profiles of lymphoid aggregates in endometriosis and eutopic endometrial samples. Transcriptional and cellular heterogeneity across tissues suggests that LA+ and LA- endometriosis may represent clinically-relevant disease subgroups.
